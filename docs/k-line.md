# K 线：一个时间窗口里的四个价格

K 线把一段时间里的价格收成四个数：开盘、最高、最低、收盘。英文图上叫 candlestick 美/ˈkændlstɪk/ 蜡烛台。Binance、TradingView、DexScreener 上那些红绿柱就是这个。

四个数的定义：

| 名称 | 这个窗口里它是什么 |
| --- | --- |
| 开盘价 Open | 第一笔价格 |
| 最高价 High | 出现过的最高价格 |
| 最低价 Low | 出现过的最低价格 |
| 收盘价 Close | 最后一笔价格 |

最高和最低经常既不是开盘，也不是收盘。只把每根收盘价连成线，这两个极值会丢。

蜡烛图从日本米市来，后来的技术分析书通常把它算在 18 世纪米商本间宗久名下。汉语叫 K 线，一般认为这个 K 来自日语「罫線」（けいせん，keisen）。也叫蜡烛图、阴阳线。口语里特别长的影线叫插针。

下面全程用一组虚构价格，不是某天的真实行情。订单簿上这四个数来自成交；AMM 上行情站怎么取样，放在最后一节。

## 实体和影线

收盘高于开盘，这根是**阳线**。收盘低于开盘，这根是**阴线**。开盘等于收盘，实体缩成一条横线，叫十字星。

实体是开盘和收盘之间的距离。竖线伸出实体的两段是影线：上影线接到最高价，下影线接到最低价。实体的上沿是开盘和收盘里较高的那个，下沿是较低的那个。阳线收盘在上；阴线收盘在下。

```text
阳线 C 在上沿                 阴线 O 在上沿

     H                            H
     |                            |
+----+----+                  +----+----+
|         | C                |         | O
|         |                  |         |
|         |                  |         |
+----+----+ O                +----+----+ C
     |                            |
     L                            L
```

H 最高价，L 最低价，O 开盘价，C 收盘价。

![阳线收盘在实体上沿，阴线收盘在实体下沿。竖线两端是最高价和最低价。](./images/k-line-anatomy.svg)

用一根 1 小时线当例子。10:00 的价格是 2000，11:00 的价格是 2040，这一小时里到过 2100，也到过 1920。

| 量 | 算法 | 这根小时线 |
| --- | --- | --- |
| 开盘 | 窗口内第一笔 | 2000 |
| 最高 | 窗口内最大值 | 2100 |
| 最低 | 窗口内最小值 | 1920 |
| 收盘 | 窗口内最后一笔 | 2040 |
| 实体 | \|收盘 − 开盘\| | 40 |
| 上影线 | 最高 − max(开盘, 收盘) | 60 |
| 下影线 | min(开盘, 收盘) − 最低 | 80 |
| 振幅 | 最高 − 最低 | 180 |
| 涨跌额 | 收盘 − 开盘 | +40 |
| 涨跌幅 | (收盘 − 开盘) / 开盘 | +2% |

振幅 180，相对开盘是 9%。涨跌幅只有 2%。这根线“涨了 2%”，同时价格在开盘上下走过相当于 9% 的范围。

从最低价 1920 算到最高价 2100，收盘 2040 走完了整段振幅的 2/3，上方还留着 1/3。下影 80 加实体 40，等于收盘离最低价的 120。

## 颜色以图例为准

本文的图用绿色画阳线，红色画阴线。Binance、TradingView 的默认主题、多数 DEX 行情站也是绿涨红跌。

同花顺、东方财富这类 A 股软件里，红色通常代表涨，绿色通常代表跌。同一根阳线，换一个软件，颜色会倒过来。

先看图例，或者直接比开盘和收盘。收盘高于开盘就是阳线，跟填成红还是绿无关。

还有一种空心画法：阳线画空心，阴线画实心。空心不是“没有成交”。图表类型名叫 Candles 时，阳线阴线都是实心，靠颜色区分；名叫 Hollow Candles 时，空心表示涨。

## 同一段行情，换周期就不一样

K 线先把时间切成等长的窗口，再在每个窗口里取四个价格。窗口的长度就是周期：1 分钟、15 分钟、1 小时、4 小时、1 日。周期按钮换的是桶的宽度。

上面那根小时线，拆开是四根 15 分钟：

| 窗口 | 开 | 高 | 低 | 收 | 涨跌额 | 成交量 |
| --- | --- | --- | --- | --- | --- | --- |
| 10:00–10:15 | 2000 | 2030 | 1990 | 2020 | +20 | 120 |
| 10:15–10:30 | 2020 | 2100 | 2010 | 2080 | +60 | 180 |
| 10:30–10:45 | 2080 | 2090 | 1920 | 1950 | −130 | 400 |
| 10:45–11:00 | 1950 | 2050 | 1940 | 2040 | +90 | 220 |
| **10:00–11:00** | **2000** | **2100** | **1920** | **2040** | **+40** | **920** |

四根涨跌额相加：20 + 60 − 130 + 90 = 40，等于小时线的涨跌额。最高价和最低价不能相加，要在所有窗口里重新取一次最大和最小。成交量可以相加。

相邻两根的收盘和开盘在这张表里接上了：2020、2080、1950。这是因为例子里每个窗口都有成交，而且下一笔紧跟着上一笔。中间若没有成交，下一根的开盘就是新窗口里的第一笔，可以不等于上一根的收盘，图上两根之间会断开。股票隔夜经常这样。加密货币 24 小时有成交时，断开会少很多。

![同一小时的四根 15 分钟 K 线，合成一根实体较短的 1 小时阳线。下方柱是成交量。](./images/k-line-timeframe.svg)

这张图按价格差画了比例。看的时候对一下这几件事：

小时线是一根阳线，实体只有 40，上影 60，下影 80。单看这一根，知道的是：这一小时结束时比开始时高 40，期间到过 2100 和 1920。先到哪一头，这根线上没有。

15 分钟图把顺序补上。前 30 分钟涨到 2100，第二根收在 2080，离最高只差 20。10:30 那根从 2080 收到 1950，最低 1920，实体很长。10:45 那根再从 1950 拉到 2040，小时线才收成阳线。

所以小时线的下影，是后一根 15 分钟拉回去的，不是价格在 1920 上瞬间弹回。最高 2100 写在第二根的影线上，最低 1920 写在第三根的影线上。两条收盘价连线都碰不到这两个数。

10:30 那根的成交量是 400，占这一小时 920 的将近一半。合成小时线之后，量通常只剩一根 920 的柱，下跌那一段的量就被加进总数里了。

周期变长，信息变少。1 小时图上看见的每根影线，都值得把周期缩一档，看它是一根线内部完成的，还是后面几根补上的。

日线的切法由行情源决定。Binance 的日线、周线以 UTC 00:00 为界。TradingView 上同一交易对，交易所不同，切日的时钟可以不同。A 股日线按交易日，上午和下午合成一根。

图表最右边那根，如果窗口还没结束，收盘价就是此刻的最新价，最高价和最低价还会被新成交改写。已经结束的窗口，四个价格就固定了。

## 影线只说明价格到过那里

上影线长，是说这个窗口里出现过明显更高的价格，收盘时价格已经离开那个高点。下影线长，是说出现过明显更低的价格，收盘时已经离开那个低点。

它不记录是谁成交的，也不记录下一根会不会反向。薄市场上，一笔成交就能把价格打到极值再打回来，影线会很长，实体可以很短。

上一节的小时线就是这种外形：实体 40，两根影线合起来 140。外形本身只复述那四个价格。

技术分析书里给常见外形起了名字。门槛是约定，不是交易所规则。例如很多书写锤子线时，要求下影至少是实体的两倍，上影很短。换一个软件，十字星的判定阈值也会变。

![六种常见形状：光头光脚阳线、长上影、长下影、十字星、看涨吞没、黄昏星。](./images/k-line-patterns.svg)

| 形状 | 用价格关系来认 |
| --- | --- |
| 光头光脚阳线 | 开盘 = 最低，收盘 = 最高，没有影线 |
| 光头光脚阴线 | 开盘 = 最高，收盘 = 最低 |
| 长上影 | 上影明显长于实体。实体靠近最低价时，上涨之后的这根常被叫射击之星；下跌之后的同形常被叫倒锤子 |
| 长下影 | 下影明显长于实体。实体靠近最高价时，下跌之后叫锤子线，上涨之后叫上吊线 |
| 十字星 | 开盘和收盘几乎相同，实体成一条横线。上下影可长可短 |
| 看涨吞没 | 前一根阴线，后一根阳线，后一根的实体完全包住前一根的实体。包住影线不是这个名字的条件 |
| 看跌吞没 | 前阳后阴，阴线实体包住阳线实体 |
| 黄昏星 | 一段上涨之后：一根阳线，一根实体很小的线，再一根阴线，而且这根阴线收进第一根实体的内部 |
| 早晨星 | 黄昏星的镜像，出现在一段下跌之后 |

锤子和上吊的四个价格关系相同。名字不同，是因为它们前面那一段一个是下跌、一个是上涨。射击之星和倒锤子也是同一套几何，差别在前趋势。

这些名字描述的是已经走完的窗口。下一根怎么走，不在名字里。

## 成交量柱

K 线下方那一排柱子和上面的价格共用时间轴。柱高是这个窗口的成交量。颜色通常跟着那根 K 线走。

成交量的单位看行情源：交易所现货常按基础资产的个数计，也可能按成交额计。读之前看轴上的单位。DEX 行情站上，一笔大额 swap 就能把一根柱打得很高，同时在价格上走出长影线。

价和量放在一起，多出来的事实是：这个方向发生的时候，成交密不密。密，只说明这个窗口里成交多。上一节里，这一小时将近一半的量落在 10:30 那根阴线上；只看小时量柱 920，这个分布不在了。

## 容易看成 K 线的三样东西

**分时图**是最新价按时间连成的线，不切窗口，没有开高低收四个数。A 股软件里分时和 K 线通常是两页。

**美国线**（OHLC bar）没有方块实体。一根竖线从最低画到最高，向左的短横是开盘，向右的短横是收盘。信息和 K 线相同。

**平均 K 线**（Heikin Ashi）用前后两根做了平滑，图上的开盘和收盘不是真实成交价：

```text
HA 收盘 = (开盘 + 最高 + 最低 + 收盘) / 4
HA 开盘 = (上一根 HA 开盘 + 上一根 HA 收盘) / 2
HA 最高 = max(最高, HA 开盘, HA 收盘)
HA 最低 = min(最低, HA 开盘, HA 收盘)
```

平均 K 线看起来趋势更顺。拿它去对真实的开盘价、收盘价，会对不上。看图时先确认图表类型是普通 K 线。

穿过蜡烛的平滑曲线，一般是收盘价做出来的均线，是后加的指标。MACD 一类也是用收盘价再计算的。读 K 线本身时，可以先把指标关掉，只留价格和成交量。

## 看一张图的顺序

1. 看纵轴是哪个价格。ETH/USDC 往上，是 ETH 变贵。报价方向反过来，涨跌就反过来。
2. 看周期，以及日线从哪个时区切开。最右边那根如果还没走完，高、低、收都会变。
3. 看颜色图例。也可以不看颜色，直接比每根的开盘和收盘。
4. 看最近一串已经走完的实体往哪边排。单根影线改不了这一串的方向。
5. 看最后一根走完的线：涨跌幅是多少，振幅是多少，收盘离最高和最低各有多远。
6. 把周期缩小一档，确认影线是在一个小窗口里走完的，还是后面几个小窗口补上的。
7. 看成交量堆在哪几根上，以及量的单位。
8. 纵轴如果是对数坐标，同样的像素在高价区代表更大的价格差。比影线长短时，读价格数字。
9. 确认这张图的成交来自哪个市场。同一个 ETH，交易所现货和某个很薄的池子，影线不会一样。

## 链上的价格不是一根 K 线

行情网站上的 K 线是索引器按时间窗口聚合出来的。Uniswap V3 池子里不存开高低收。

池子当前价在 `slot0.sqrtPriceX96`。另有一组按秒累计的 tick，用来算时间加权平均价（TWAP）。TWAP 是这段时间的平均；K 线是开、高、低、收。价格在高位停留很久、在低位只停一个区块时，平均会偏向高位，而 K 线的最低价仍然记着那个低点。单看蜡烛读不出 TWAP。

池子里的价格定义为 token1 / token0，也就是 1 个 token0 值多少 token1。token0 是地址较小的那个。主网 USDC `0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48` 的地址小于 WETH `0xC02aaA39b223FE8D0A0e5C4F27eAD9083C756Cc2`，所以在 USDC/WETH 池里 token0 是 USDC，token1 是 WETH。这个原始价格变大，表示 1 USDC 能换到更多 WETH，也就是 ETH 的美元价格在跌。网站上标着 ETH/USDC 的 K 线，纵轴通常已经换成「1 ETH 多少 USDC」，方向和池子原始价格相反。

订单簿的一根 K 线来自一笔笔成交。AMM 行情站通常取每次 swap 之后的池子现价；一笔大 swap 自己会沿着 tick 走出一段路径，最高和最低可以来自同一笔交易。流动性稀的区间里，这一笔就能把价格打得很远，套利再打回来。图上是一根很长的影线，尖端对应池子真实到过的价格，停留时间可以只有一个区块。

不同网站对「一笔价格」的取样不一样，有的只用区块结束时的价格，区块内部的路径就不会出现在影线上。读之前先确认图的来源是哪一个池子或哪一个订单簿。

## 从一串价格自己算

窗口里的价格按时间排好，记为 `price[0 .. n-1]`：

```text
open  = price[0]
close = price[n-1]
high  = max(price)
low   = min(price)

上影线 = high - max(open, close)
下影线 = min(open, close) - low
```

这个窗口一笔价格都没有，就没有这根线。不要用 0 填出一个价格。

窗口还没结束时，`close`、`high`、`low` 只用到目前为止的价格，后面的成交会改它们。

多个小窗口合成一个大窗口：大窗口的开盘等于第一根的开盘，收盘等于最后一根的收盘，最高等于所有最高里的最大，最低等于所有最低里的最小，成交量等于各根成交量之和。涨跌额可以相加。最高价、最低价、影线都不能把小窗口的结果直接加起来。
